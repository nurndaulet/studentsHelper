# Smart Student 🎓

React Native + **Expo SDK 57** негізіндегі қазақша студент көмекшісі. Суреттегі ақ-көк минимал стиль: үлкен карточкалар, дөңгелек батырмалар, инициалдары бар профиль аватары және жеке кітап/құсбелгі иконкасы.

## Мүмкіндіктер

- Апталық сабақ кестесін платформаңыздан қарап **қолмен енгізу**: пән, күн, уақыт, аудитория, оқытушы, сабақ түрі және түсі.
- Бір күндегі сабақ уақыттарының қабаттасуын тексеру.
- Үй тапсырмаларын пәнге байланыстыру, дедлайн, түсіндірме және орындалу белгісі. Мерзімі өткен тапсырмалар ерекшеленеді.
- Материалдарды қолмен енгізу: мәтіндік конспект, атау және HTTPS/HTTP сілтемесі; пән бойынша байланыстыру, іздеу.
- Басты бетте бүгінгі сабақтар, келесі/ағымдағы сабақ және жақын дедлайндар.
- Профильді өңдеу; барлық жазбаларды өңдеу және өшіру.
- Құрылғыдағы AsyncStorage жады. Интернетсіз деректерді енгізуге болады; сыртқы сілтемелер интернетті қажет етеді.

Бұл нұсқада сервер, аккаунтпен авторизация, платформадан автоматты импорт, push-хабарлама, файл тіркеу немесе құрылғылар арасында синхрондау жоқ. Материал — мәтін не сілтеме. Профильді бастау — кіру жүйесі емес. Қосымшаны өшіргенде немесе браузер жадын тазартқанда деректер жойылуы мүмкін.

## Өз компьютеріңізде іске қосу

1. Node.js **22.13+ LTS** (немесе Node 24 LTS), Git орнатыңыз.
2. Терминалда:

```bash
git clone https://github.com/nurndaulet/studentsHelper.git
cd studentsHelper
npm ci
npm start
```

3. Телефон мен компьютерді бір Wi-Fi желісіне қосыңыз. **SDK 57-мен үйлесімді Expo Go** арқылы QR-кодты ашыңыз (Android-та Expo Go ішінен, iPhone-да камерадан).
4. Егер Expo Go басқа SDK нұсқасын ғана қолдаса, Android үшін SDK 57-ге сәйкес Expo Go нұсқасын қолданыңыз немесе development build жасаңыз. iOS-та бұрынғы Expo Go нұсқасының қолжетімділігі шектеулі; сәйкес development build қажет болуы мүмкін.

Браузерде тексеру:

```bash
npm run web
```

Android эмуляторы: Android Studio және іске қосылған эмулятор қажет; `npm run android`. iOS симуляторы: тек macOS + Xcode; `npm run ios`.

Қосымшаны ашқанда атыңызды енгізіп «Бастау» басыңыз. «Кесте» → күнді таңдаңыз → «+ Сабақ». «Тапсырма» және «Материал» бөлімдерінен сол пәнге жазбаларды қосыңыз. Уақыт `09:00`, дедлайн `2026-10-25` форматында енгізіледі.

## Тексерулер

```bash
npm test
npm run export
```

`export` Android/iOS JavaScript бандлдарын және web жинағын тексереді; APK/IPA жасамайды. Телефондағы нақты тексеруді алмастырмайды.

Браузердегі толық сценарий (екінші терминалда `npm run web` іске қосулы болсын):

```bash
npx playwright install chromium
npm run test:e2e
```

Жүйеде Chromium орнатылған болса, Linux-та `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` қолдануға болады.

## Android APK құрастыру (қосымша)

Expo аккаунты және EAS қызметі қажет:

```bash
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

`eas.json` preview профилі APK құрады. Алғашқы іске қосуда EAS жобаңызды тіркеуін ұсынады. iOS тарату үшін Apple Developer аккаунты қажет. Бұл репозиторийге дайын APK/IPA немесе дүкенге жариялау кірмейді.
